# Pro-24 - Advanced GSAP Gaming Website

A modern, immersive, and highly interactive web application template featuring fluid GSAP animations, dynamic video backgrounds, tilt-effect cards, and integrated audio controls.

## ✨ Features

- **Cinematic Boot Sequence:** Interactive preloader with real-time progress indicators and status updates.
- **Dynamic Hero Section:** Multi-video background integration supporting seamless transition layers and picture-in-picture video previews.
- **Scroll & Mask Animations:** Advanced viewport clip-path masking and dynamic text reveals.
- **Interactive Tilt Grid:** Responsive tilt-reactive feature cards powered by JavaScript modules, showcasing ecosystem components (RADIANT, Zigma, Nexus, Azul) with autoplaying video loops.
- **Multiversal Visuals:** Depth-tracked interactive imagery and mouse-following decorative elements.
- **Ambient Audio Integration:** Toggleable background music with synchronised soundwave UI indicators.
- **Performance Optimised:** Includes web font preloading (`.woff2`), compressed WebP graphics, and responsive asset delivery.

## 🛠️ Tech Stack

- **Core Markup:** HTML5 (Semantic, accessible layout structure)
- **Styling:** CSS3 / Custom Minified Styles (`css/index.min.css`)
- **Interactivity & Animation:** JavaScript / ES Modules / GSAP (`js/index.min.js`)
- **Assets:** Custom typography (`zentry-regular`, `robert-regular`, `robert-medium`), compressed WebP imagery, and MP4 video loops.
